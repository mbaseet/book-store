# How It Works visuals

These are the original transparent PNGs supplied for the Mint Meow “How it works” experience. They are kept here as source artwork so the storefront does not depend on files in Downloads.

- `step-choose-worlds.png` — choose a story or world
- `step-upload-photo.png` — upload a child photo for personalization
- `step-finished-book.png` — the finished storybook moment
- `step-extra-book.png` — additional supplied book visual, reserved for a future use

The optimized storefront references live in `public/brand/how-it-works-*.png`.

The original upload bundle is also retained as `Bring-Your-Childs-Story-source.zip`.
